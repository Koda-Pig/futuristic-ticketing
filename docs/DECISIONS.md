# Decisions

Choices made where docs/PLAN.md was ambiguous or had to change. Newest last.

| Date       | Area             | Decision                                                                                                                                                                                                                                                                                                                                                                                                                         | Why                                                                                                                                    |
| ---------- | ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| 2026-11-23 | Tooling          | pnpm instead of npm. Wherever the plan says `npm run x`, use `pnpm x`                                                                                                                                                                                                                                                                                                                                                            | Faster installs; one lockfile                                                                                                          |
| 2026-11-23 | Shell budget     | ≤850k triangles (was 300k)                                                                                                                                                                                                                                                                                                                                                                                                       | The terraces, fascia rails and trusses tore below that; v1 is desktop-only. See docs/ASSETS.md                                         |
| 2026-11-23 | Skyboxes         | The model has no enclosed boxes; the east leather seating is an open hospitality tier. VIP interiors are procedural (§7.4)                                                                                                                                                                                                                                                                                                       | Inspection in M1: the dark "windows" are opaque panels on solid concrete                                                               |
| 2026-11-23 | Inspector        | The M1 inspector stays plain JS (`src/inspector.js`), loaded lazily from `main.tsx` for `?debug=shell` and `?debug=materials` only                                                                                                                                                                                                                                                                                               | Keeps the working tool without pulling it into the React app bundle                                                                    |
| 2026-11-23 | Testing          | The R3F canvas sets `data-ready` in `onCreated`; e2e waits for it                                                                                                                                                                                                                                                                                                                                                                | Lets tests tell R3F's context apart from one the test creates                                                                          |
| 2026-11-23 | Hosting          | Netlify instead of Vercel. Read "Vercel" in the plan as Netlify, including the deploy-preview origin in `embed.allowedOrigins` (§12)                                                                                                                                                                                                                                                                                             | Already deployed there                                                                                                                 |
| 2026-11-23 | Bowl fit         | Cape Point's bowl was measured from the shell's concrete treads, not fitted by eye. Rows are 0.8 m deep with risers of 0.36/0.40/0.44 m (lower/middle/upper); tiers start 0, 16 and 28.85 m out from the outline (43 × 62.5 m, exponent 32: nearly rectangular, with the pitch along Z). The middle and upper tiers' rounded corners come from offsetting along the normal, as §6 says. 97% of seats sit within 10 cm of a tread | Eyeballing in `?calibrate` left corner seats metres off; a lower exponent rounds the corners too early                                 |
| 2026-11-23 | Venue schema     | Added `tiers[].rowsByStand` (the ends rake back further: lower 20 rows, middle 16, against 12 and 10 elsewhere; the east middle tier is 0, since it is the model's hospitality seating) and `voids`, plan-view rectangles with no seats (the shell's vomitories and stair landings). `baseHeight` is the front row's tread; seat pans sit 0.45 m above it                                                                        | The shell's terraces are not uniform around the bowl                                                                                   |
| 2026-11-23 | Capacity         | Cape Point has ≈30.4k generated seats, not ≈34k                                                                                                                                                                                                                                                                                                                                                                                  | That is what the shell's terraces hold                                                                                                 |
| 2026-11-23 | Seat facing      | The generator test allows seats to face up to 60° off the centre spot (§6 said 30°)                                                                                                                                                                                                                                                                                                                                              | In a near-rectangular bowl, seats near a corner face straight across, as in real stadiums                                              |
| 2026-11-23 | Far LOD          | One `InstancedMesh` per tier with per-instance colour, instead of a merged geometry with vertex colours                                                                                                                                                                                                                                                                                                                          | Same single draw call per tier; recolouring a seat (M4) is one `setColorAt`                                                            |
| 2026-11-23 | Fly-in pose      | The block fly-in camera sits 7 m above the mid row, not 10 m. At 10 m all 48 upper-tier poses and 4 middle-tier poses were inside or behind the shell roof; 7 m at 18 m out clears every block (raycast against `shell.glb`)                                                                                                                                                                                                     | Upper-tier blocks were a wall of concrete after entering                                                                               |
| 2026-11-23 | Embed origins    | The Netlify deploy-preview origin isn't written into `venue.json`; the build reads `DEPLOY_PRIME_URL` and `MockDataSource` adds that origin to `embed.allowedOrigins` at load. The UI accent (Upgrade button, chosen recliner) comes from `branding.accent` via `--accent`                                                                                                                                                       | Preview URLs change per deploy; Riverside must look white-labelled with no code changes                                                |
| 2026-11-23 | Adaptive quality | drei `PerformanceMonitor` steps between three levels: DPR 1.5 with post-processing, DPR 1 with post-processing, DPR 1 without. Shadows stay on at every level, but the shadow map is cached and refreshed every 20th frame                                                                                                                                                                                                       | The scene is static apart from the camera; caching the shadow pass halved per-frame triangles, which was cheaper than dropping shadows |
| 2026-11-23 | Loading          | A static "Loading stadium…" line in `index.html` covers the bundle download. A full-screen loader covers the time until the first frame, then a slim `useProgress` bar tracks the shell GLB while the scene is already interactive                                                                                                                                                                                               | §13 wants the first interactive frame before the shell arrives, so the loader must not wait for it                                     |
| 2026-11-23 | Smoke timing     | The 90 s limit in the Playwright smoke test is asserted only when it runs in Google Chrome on the GPU (`GPU=1`); CI runs the same flow without the timing check                                                                                                                                                                                                                                                                  | SwiftShader takes ~105 s for the same flow (on a GPU: 4 s)                                                                             |
| 2026-11-23 | Embed origins    | The build also adds Netlify's production `URL` origin, not only `DEPLOY_PRIME_URL` (`import.meta.env.EMBED_ORIGINS`)                                                                                                                                                                                                                                                                                                             | `embed-test.html` on the production site must pass the allowlist                                                                       |
